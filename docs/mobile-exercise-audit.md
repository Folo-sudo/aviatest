# Audit telephone des exercices

Ce document sert de reference produit pour la version telephone.

## Legende

- `dedicated` : une variante mobile specifique existe deja.
- `responsive` : le test peut etre propose sur telephone sans branchement separe immediat.
- `needs-work` : une vraie variante telephone reste souhaitable pour une experience correcte.
